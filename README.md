# test

Repository latihan Git dan GitHub untuk mencoba branch, commit, dan pull request.

## Mulai

```sh
git clone https://github.com/kaw0ru/test.git
cd test
git switch -c latihan/perbaikan-readme
```

## Alur kontribusi

1. Fork repository ini jika kamu belum memiliki akses tulis.
2. Buat branch untuk perubahan yang ingin dikerjakan.
3. Edit file, periksa perubahan, lalu buat commit dengan pesan yang jelas.
4. Push branch ke repository milikmu dan buka pull request ke `kaw0ru/test`, branch `main`.
5. Tunggu maintainer memeriksa dan melakukan merge.

Jika sebuah commit dikerjakan bersama, cantumkan `Co-authored-by: Nama <email>`
di akhir pesan commit, setelah satu baris kosong. Gunakan email yang terhubung
ke akun GitHub co-author.
